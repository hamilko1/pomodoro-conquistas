# Testes

## Testes automatizados
`python -m pytest` executa a suíte (modelos, API, telas, CSRF e regras de conquistas/metas/estatísticas) em SQLite em memória.

## Testes com usuários (Situação 3)
- Formulário entregue aos testadores: `Formulario_de_teste_Pomodoro.docx` (adicione aqui).
- Formulários preenchidos pelos 5 testadores: pasta `formularios-preenchidos/`.
- Evidências (prints dos erros): pasta `evidencias/`.
- Laudo de qualidade: `laudo_de_qualidade.md` (a ser escrito com base nos formulários reais).
